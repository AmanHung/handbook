# 實習生 OSCE、DOPS 與儀表板

實習生在「學習評估」使用與 PGY 共用的 OSCEAssessment、DOPSAssessment 畫面。PGY 仍使用原 GAS 介面；實習生經轉接層保存至原有的 intern_passports/{studentUid}/entries，並沿用伺服器確認、實際填寫者及追加版本的紀錄方式。

頁首「實習生訓練計畫」可另開 PDF 閱讀完整計畫書與附件。PDF 由使用者提供的《藥劑科實習生訓練計畫11409.docx》直接轉出，保留原內容與表單，隨網站一併提供。

## 評核與回饋

- OSCE 保留實習計畫四站、逐項 1–5 分及整體 0–10 分，通過與否由教師判定。教師送出後，實習生填寫該次評核的心得及自覺加強內容。重測另建評核，不沿用前一次回饋。
- DOPS 依實習生訓練計畫 11409 化療調劑安全訓練 2.1 及附件 5，僅提供「抗腫瘤藥物調配作業安全防護裝備」一份表單，沿用 PGY 的填寫與回饋流程。教師可暫存草稿或送出給學生；實習生可暫存回饋或完成。教師與學生簽名由各自保存紀錄的稽核身分產生。
- DOPS 整體 6 分以下重新訓練並於 1 個月後重測；7 分於 1 週後重測；8 分以上完成回饋後結案。PPE 另外要求十二項皆符合。
- PPE 為實習安全訓練必修，儀表板、待辦、完成數及結訓檢核僅計算該項 DOPS。其他 PGY DOPS 表單不提供實習生新增評估；若有既有紀錄，仍可由後台檢視，不列入實習生檢核。新版 PPE 評核連動安全訓練；舊版 PPE 及 OSCE 紀錄保留。
- 實習生介面不宣稱已寄送 Email；本次實習流程使用護照及後台待辦追蹤。

## 後台儀表板與紀錄

原後台的「儀表板 → 實習生護照」可切換梯次、個別及全部實習生。共用 PGY 的統計卡與評分圖表，提供 OSCE、DOPS 已達標、待學員回饋、待加強／重評、尚未評核狀態、六大領域進度與學員矩陣。OSCE 圖表不設自行推定的數值及格線。

從待辦可開啟對應評估；紀錄清單保留教師草稿、送出、學員回饋與重測版本。後台提供完整評分與回饋檢視，不提供 CSV／JSON 匯出按鈕。

## 發布與驗證

先發布經模擬器驗證的完整 firestore.rules，再更新網站。docs/intern-passport.rules.fragment 僅供合併參考，不能覆蓋完整規則。

讀取權限維持教師／管理員及學員本人；新回饋只接受心得、加強內容、流程與實際評核參照，不接受教師評分或偽造簽名。同一學員、站別與教師已送出評核的參照由資料庫規則檢查。

- npm run test:passport：含實習 DOPS 項目限制、既有紀錄保留、四站 OSCE、回饋對應、重測門檻、PPE 與儀表板統計。
- npm run test:passport:integration：使用本機 Firestore 模擬器，驗證實際儲存、本人回饋、拒絕偽造分數／錯誤評核連結，以及現有 PGY、教材、閱讀確認規則相容性。
- GitHub Actions 另執行既有指定 ESLint 與正式建置。
